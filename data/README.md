# Data

Nothing in this folder is committed except this file and the `.gitkeep` placeholders.

- `raw/`: the Joint EVS/WVS 2017 to 2021 file (ZA7505 v2.0.0) and its codebook.
- `external/`: country-level sources in subfolders `vdem/`, `eiu/`, `worldbank/`.
- `derived/`: files written by the scripts in `R/` (`individual.rds`, `country_year.rds`, `analytic.rds`, `imputations.rds`).

Download instructions, versions and access dates: `docs/data_sources.md`.
