# Agent guidance

This repository is a preregistered robustness study. Before any work:

1. Read [CLAUDE.md](CLAUDE.md). Its rules apply to every agent, not only Claude. The most important one: no model of the outcome is fitted until the plan is registered.
2. Read the current task in [docs/CURSOR_HANDOFF.md](docs/CURSOR_HANDOFF.md).

Use [README.md](README.md) for the layout and the order in which scripts run. Preserve unrelated local changes. Never commit anything under `data/`.
